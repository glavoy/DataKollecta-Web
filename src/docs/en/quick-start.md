# Quick start

This checklist takes you from a new account to your first uploaded record. Each step links to more detail.

## 1. Create your account

On the home page, choose **Sign Up**. Enter your name, email and a password of at least 10 characters. Then confirm your email address using the link we send you. → [Signing up and your account](/docs/account)

## 2. Create a project

Go to **Projects → Create Project**. Give it a name and a **project code**, for example `household_2026`. Field workers type the project code into the app, and it **can't be changed later**, so keep it short and easy to type. → [Creating a project](/docs/projects/create)

## 3. Add your colleagues (optional)

Open the project's **Members** tab. Choose **Add Member**, search for a colleague by email, and pick a role. Your colleague must have signed up first. → [Members](/docs/people/members)

## 4. Create field-team logins

On the **Field Team** tab, choose **Add Credential**. Create a username and password, for example `surveyor1`, for each data collector or device. → [Field team](/docs/people/field-team)

## 5. Build a survey

On the **Surveys** tab, choose **Create New Survey** to open the Survey Designer. If you already have a package from SurveyGen, choose **Upload ZIP** instead. → [The Survey Designer](/docs/designer/overview) · [Tutorial](/docs/designer/tutorial)

## 6. Test it on a phone

In the designer, clear any errors in the **Issues** panel, then choose **Promote to Test**. Install the field app on a phone and sign in with the project code and a field-team login. Then download the `[TEST]` survey and run a few practice interviews. Sync them, and check that they appear on the **Data** tab under the **Test** filter. → [Testing and deploying](/docs/designer/test-and-deploy)

## 7. Deploy

When you are happy with the survey, sync every test device first. Then choose **Deploy**. The survey is now locked and live. Field workers receive it the next time they sign in. → [Surveys and their status](/docs/surveys/overview)

## 8. Watch the data arrive

The **Overview** tab shows how many records each survey has collected. Use the **Data** tab to browse records and export them to CSV. → [Viewing records](/docs/data/browse) · [Exporting data](/docs/data/export)
