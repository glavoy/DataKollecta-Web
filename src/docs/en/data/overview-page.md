# The Data page

**Data** in the left sidebar gives an overview of the data across **all** the projects you belong to.

- **Totals**: the number of projects, forms and records you can see.
- **Projects table**: each project with its project code and record counts. Use **Search projects…** to filter it.
- **View Data** opens that project's [Data tab](/docs/data/browse), where you can browse and export records.

What you see depends on your membership: only projects you belong to, in any role, are included.
