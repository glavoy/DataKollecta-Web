# Roles and permissions

Each [member](/docs/people/members) of a project has one of three roles, and the role applies to that project only. One person can be an owner of one project and a viewer of another. The roles in all your projects are listed on **My Account**.

## Permission matrix

| **People** | | | |
| See members and field team | ✓ | ✓ | ✓ |

| **Data** | | | |

| Export to CSV | ✓ | ✓ | ✓ |
| Reclassify records as test or deployed | ✓ | | |
| See, create and revoke [data feed keys](/docs/data-feeds/overview) | ✓ | | |

## Choosing roles

- **Owner**: the principal investigator or study manager. They are responsible for who has access and for the data lock. Have at least two.
- **Editor**: survey designers and field coordinators.
- **Viewer**: data managers, statisticians and monitors who need to read and export data but shouldn't change the study.

> **Every role can export data.** Only add people who are allowed to see the study's data.
