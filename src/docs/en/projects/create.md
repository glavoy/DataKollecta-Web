# Creating a project

A project holds everything for one study: its surveys, collected data, website members, field-team logins and settings. Any signed-in user can create a project, and the person who creates it becomes its **owner**.

## Create a project

1. Choose **Projects** in the left sidebar.
2. Choose **Create Project**.
3. Fill in:
   - **Project Name**: the full name people will see, for example *PRISM Cross-sectional Study*.
   - **Project Code**: a short code that is filled in for you from the name. You can edit it. It may contain only lowercase letters, digits, hyphens (`-`) and underscores (`_`).
   - **Description** (optional): a sentence about the study's goals.
4. Choose **Create Project**.

![The Create New Project dialog](/docs/img/projects/create-project.jpg)

The new project appears in your Projects list. Click it to open it.

## Choosing a good project code

Field workers **type the project code into the app** to sign in, often on a phone keyboard, so:

- Keep it short and easy to type, for example `prism26` rather than `prism-cross-sectional-study-2026`.
- Avoid characters that look alike, such as `l` and `1`, or `o` and `0`.
- Choose carefully. **The project code can't be changed after the project is created**, because devices that are already signed in depend on it.
