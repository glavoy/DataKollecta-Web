# Projects list and Overview

## The Projects list

**Projects** in the left sidebar lists every project you belong to. Each card shows the project's name and status.

- **Search** filters the list by name.
- The filter menu switches between **Active** (the default), **Archived** and **All** projects.
- **View Project** opens the project.
- Owners can **Archive** or **Unarchive** a project from its card. See [Project settings](/docs/projects/settings#access-and-visibility) for what archiving does.

![The Projects list, filtered with the search box](/docs/img/projects/projects-list.jpg)

## Inside a project

The header shows:

- the project's name
- its status (**Active** or **Paused**, plus **Archived** if it has been archived)
- **your role** in the project
- its **project code**

Below the header, the project is split into tabs:

| Tab | What it's for |
|---|---|
| **Overview** | A summary of the project at a glance. |
| **Surveys** | Create, upload, version and deploy surveys. See [Surveys](/docs/surveys/overview). |
| **Data** | Browse and export collected records. See [Viewing records](/docs/data/browse). |
| **Members** | Website users and their roles. See [Members](/docs/people/members). |
| **Field Team** | Logins for the field app. See [Field team](/docs/people/field-team). |
| **Settings** | Name, description, access, data lock, deletion. See [Project settings](/docs/projects/settings). |

The address bar remembers which tab you are on, for example `?tab=data`, so you can bookmark a tab or share a link to it.

## The Overview tab

The Overview tab has four summary cards: **Surveys**, **Records**, **Project Members** (website users) and **Field Team** (app logins). Click a card to jump to its tab.

![A project's Overview tab](/docs/img/projects/project-overview.jpg)

The **Records** card also says how many of the records are test data. When records have been uploaded, a **Data Collection Summary** shows how many records each survey has collected.

A brand-new project shows a **Get Started** card instead. Its button opens the Survey Designer.
